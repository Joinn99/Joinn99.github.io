Cloud Sync

Privacy Policy

Data access and use

Cloud Sync uses rclone and the Google Drive API with the drive.file permission. It uses the files and folders available under that permission to upload selected project files and to compare, verify, or restore backup copies.

Storage and sharing

Backup copies are stored in the operator's Google Drive account and follow that account's sharing settings. The rclone configuration stores the OAuth tokens on the operator's Mac. Cloud Sync transfers the selected files to Google Drive for backup and does not send their contents to other services. These informational pages do not receive Drive files or OAuth tokens.

Retention and control

The operator controls which backups are kept and can remove them in Google Drive. The operator can revoke Cloud Sync's access in Google Account connections.
